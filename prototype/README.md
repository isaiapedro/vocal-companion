# Music Practice static site prototype

Open `index.html` directly in a browser. It is the local Music Practice hub;
`vocal-practice.html` contains the deterministic Vocal Practice tool, while
Ear Training and Repertoire have dedicated coming-soon pages. The site needs no
server, package install, tracking, storage, or network access.

## Deterministic rule order

1. Pain/sudden change selects the reduced/deferred `reset` set.
2. Limited voice state or low energy also selects `reset`.
3. Otherwise the selected focus selects `pitch`, `transition`, or `phrase`.
4. Time trims or adds a transfer/mental-rehearsal block but never raises demand.
5. Style changes only the repertoire-task framing.

Vocal Practice presents its five choices in two phone-first steps, then moves
through the selected blocks with a manual-advance countdown. Its optional
reflection and all session state disappear on refresh, reset, or navigation.
It does not persist a profile, infer technical level, predict recovery, or
progress workload. Its routine rules draw on `singing-voice-science`,
`vocal-exercises-singers-scoping-review`, and related local music-practice
notes, while preserving their limits on universal exercise choice, dose, and
long-term effects.
